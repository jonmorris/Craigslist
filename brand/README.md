# Brand assets

Vector files for the redesign. The wordmark is converted to outlines, so it needs no font installed.

| File | Use |
|---|---|
| `peace-sign.svg` | the mark with the brand gradient (`#c665f2` → `#6a1fc2`) |
| `peace-sign-purple.svg` | solid brand purple `#6a2bb8` |
| `peace-sign-mono.svg` | single color via `currentColor` (black by default; recolor in Figma) |
| `craigslist-logo.svg` / `-on-dark.svg` | horizontal lockup: mark + wordmark |
| `craigslist-wordmark.svg` / `-on-dark.svg` | wordmark alone, in Young Serif |
| `app-icon.svg` | Android adaptive icon, 108dp canvas with the mark inside the 66dp safe zone |
| `icons/` | every UI icon used (Material Symbols Rounded 500), with a name list in `icons/README.md` |

Regenerate with `node scripts/logo.mjs` from `prototype/`.

These are redesign explorations for the Livefront challenge, not official Craigslist assets.
