# Design tokens — Material 3

Everything in the prototype uses only these values, so they move directly into Figma (Material 3 Design Kit) and a Jetpack Compose `MaterialTheme`. Colors are generated by `prototype/scripts/theme.mjs` with Google's `material-color-utilities`, the same engine as Material Theme Builder and Android.

## Color

- **Seed:** `#9945C8`, the purple sampled from the current app's buttons and peace sign.
- **Scheme:** generated with `SchemeFidelity`, then a hand-tuned brand layer is pinned on top: primary, the surfaces, text and outline colors, and all custom colors. The generator supplies the remaining roles (tertiary, error, inverse, scrim). Every text/background pair passes WCAG 4.5:1; the script checks this.
- **No dynamic color (Material You).** The brand purple stays fixed instead of following the wallpaper. This is a deliberate choice for a branded marketplace.

**In Figma:** create color styles from the tables below (Material Theme Builder can generate the base from `#9945C8`; then overwrite the pinned roles with these values).

## Typography

These are M3 type scale roles. The brand serif goes on title and headline roles only; Figtree goes on everything else. Sizes are in sp.

| M3 role | Font | Size / line | Weight | Used for |
|---|---|---|---|---|
| headlineSmall | Young Serif | 24 / 32 | 400 | (reserved) |
| titleLarge | Young Serif | 22 / 28 | 400 | section headings, top app bar titles, sheet titles |
| titleMedium | Figtree | 16 / 24 | 500 | tile names, button labels |
| titleMedium (emphasized) | Figtree | 16 / 24 | 700 | prices, current location |
| titleSmall | Figtree | 14 / 20 | 500 | tabs, saved-search names |
| bodyLarge | Figtree | 16 / 24 | 400 | search placeholder, text fields, list rows |
| bodyMedium | Figtree | 14 / 20 | 400 | listing titles, snackbar |
| bodySmall | Figtree | 12 / 16 | 400 | listing meta (age · area · distance), subtitles |
| labelLarge | Figtree | 14 / 20 | 500 | chips, FAB, text buttons |
| labelMedium | Figtree | 12 / 16 | 500 | nav labels, counts, badges |
| labelSmall | Figtree | 11 / 16 | 500 | fair-price badges, photo count |

Prices use tabular (equal-width) figures. Both fonts are free Google Fonts. In Compose, bundle them in `res/font` or use downloadable fonts.

## Components
All are standard M3 / Compose Material 3 components. Nothing is web-only.

| Prototype | Compose Material 3 |
|---|---|
| bottom navigation | `NavigationBar` + `NavigationBarItem` (5 destinations, 64×32 indicator) |
| search bar | `SearchBar` (56dp) |
| home header, list header | `TopAppBar`, with the home brand row collapsing via `TopAppBarScrollBehavior` |
| subcategory tabs | `PrimaryScrollableTabRow` |
| filter chips | `FilterChip` (32dp, 48dp touch target) |
| section tiles, saved searches | `Card` / `OutlinedCard` |
| save search | `ExtendedFloatingActionButton` (primaryContainer) |
| sort, price, save sheets | `ModalBottomSheet` |
| price min / max, search name | `OutlinedTextField` |
| alerts toggle | `Switch` in a `ListItem` |
| instantly / once a day | `SingleChoiceSegmentedButtonRow` |
| sort options | `RadioButton` rows |
| confirmations | `Snackbar` |
| price histogram | custom `Canvas` composable |

**Interaction:** M3 state layers (pressed 10%, keyboard focus 10%) stand in for the ripple. No hover states: the app is touch-first. There are no scale or web-only effects. **Motion:** emphasized-decelerate easing; sheets slide up over 400ms.
